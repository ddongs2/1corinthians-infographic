## 🌟 개요 (Overview)
본 프로젝트는 **고린도전서 1장 10-17절** 본문을 바탕으로 선포된 설교 말씀을 시각화한 반응형 HTML 인포그래픽입니다.  
사람의 이름과 당파를 내세우던 고린도 교회의 분열상을 진단하고, 찢어진 그물을 깁는 헬라어 *카테르티스메노이*(온전히 합하라)의 의미와 오직 그리스도의 십자가를 중심으로 연합하는 성도의 일상적 실천을 담았습니다.

## 📌 주요 인포그래픽 구성 (Key Sections)

1. **소그룹 vs 당파 (식별 매트릭스)**:
   - 생명을 살리는 건강한 소그룹 (열린 문, 경청, 위로, 은혜)
   - 공동체를 병들게 하는 폐쇄적 당파 & '정치질' (배타성, 험담, 기득권)
2. **바울의 원어적 통찰 (*카테르티스메노이*)**:
   - 마태복음 4:21 '찢어진 그물을 깁다'의 어원적 고찰
   - 갈등 방치가 아닌 직접 찾아가 꿰매는 성도의 수고
3. **고린도의 4개 파벌과 본질의 질문**:
   - 바울파, 아볼로파, 게바파, 그리스도파의 특징과 오늘날 교회의 기득권 언어 경계
   - *"그리스도께서 어찌 나뉘었느냐? 바울이 너희를 위하여 십자가에 못 박혔느냐?"*
4. **의도와 상처의 간극 (실제 사역 일화)**:
   - "그때 목사님 눈빛은 아니었어요" — 논리적 '의도' 주장 vs 마음에 남은 '상처'
   - 화해의 황금 문장: *"제 뜻은 이랬습니다. 그런데 제 말이 어떻게 들리셨는지도 진심으로 듣고 싶습니다."*
5. **목회 25년의 고백 & 사람 인(人)자의 섬김**:
   - "결과만큼이나 그 과정에서 사람을 어떻게 대했는가가 중요합니다."
   - 서로 기대어 지탱하는 참된 성도의 교제
6. **이번 주의 4가지 구체적 실천 & 묵상 메모**:
   - 내 옳음의 설명 멈추기, 구체적으로 사과하기, 험담에서 돌아서기, 관계 잇는 말 쓰기
   - 브라우저 로컬 저장소 기반 개인 묵상 메모장 탑재
7. **언어 생활 대조표**:
   - 관계를 벌리는 말 vs 다시 잇는 말

## 🚀 GitHub Pages 배포 안내 (How to View Online)
이 저장소의 `index.html`은 GitHub Pages를 통해 즉시 웹사이트로 호스팅할 수 있습니다.
1. GitHub 저장소 상단 **Settings** 클릭
2. 좌측 메뉴에서 **Pages** 선택
3. **Branch**를 `main` 또는 `master`의 `/ (root)`로 설정 후 **Save**
4. 약 1분 후 제공되는 GitHub Pages URL로 접속하면 모바일 및 PC 어디서나 인포그래픽을 감상할 수 있습니다.
